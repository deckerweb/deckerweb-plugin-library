# Security

[Deutsch](SECURITY-de.md)

Report vulnerabilities privately through the repository of the host plugin that embeds this Library: Security → Advisories → Report a vulnerability. No public email address is required. Include host/Library versions, WordPress/PHP versions, reproduction steps and impact; omit credentials and personal data. Do not publish unpatched security details in issues or discussions.

Maintainers must enable GitHub Private Vulnerability Reporting in each host repository and verify the form before publishing. If no reporting button exists, request that the host maintainer enable it without exposing vulnerability details publicly. GitHub configuration is external to this local kit and has not been changed by this build.

Reports are assessed confidentially, affected versions identified, a fix prepared and tested, and disclosure coordinated with the reporter after a fixed release is available. No fixed response deadline is promised. Maintenance targets the latest stable Library; older versions are assessed for necessary security fixes.
