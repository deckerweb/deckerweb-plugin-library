# Grafiken und Herkunft

[English](ASSETS.md)

Lokale Katalogicons sind originale deckerweb-Grafiken aus freigegebenen Plugin-Repositories oder geprüften Release-ZIPs. Herkunft und SHA 256 je Plugin stehen in den [Katalogquellen](CATALOG-SOURCES-0.9.0.json). Icons werden lokal ausgeliefert; die Darstellung kontaktiert GitHub nicht. Die freigegebene blau/lila 1 B-Identität, zweisprachige 1280×640-Banner, Katalogübersicht und reale Beispielscreenshots bleiben erhalten. Für diesen Release wurden keine neuen Banner oder Schriftdateien erzeugt oder mitgeliefert. Das lokale Footer-SVG ist eine Vektorgrafik. Vorhandene Grafikquellen können Systemschriften referenzieren; vorhandene Lizenzbelege bleiben bei den Grafiken. Keine Stockgrafiken und kein kommerzieller Buildercode enthalten.
