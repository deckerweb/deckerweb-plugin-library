# Release-Prüfung · 0.6.1

[English](VALIDATION-0.6.1.md)

7. Oktober 2026. Library 0.6.1. Das Update erlaubt Daily-Scripture-Netzwerkaktivierung ab installierter Version 1.0.0, mit manifestgeprüfter Übergabe von älteren Library-Instanzen bei Erstaktivierung und vorsichtiger Altleser-Katalogregel.

Aktuell geprüft: freigegebene Original-ZIPs, versionsabhängige Voraussetzungen, Altleser, unabhängige Caches/Updater-Brücke, Erstaktivierung und Ablehnung defekter Manifeste. Daily Scripture 1.0.1 ist in einer isolierten Kopie vorbereitet; Datenhaltung bestehender/neuer Websites und Bezugswebsite im Network Admin sind dort geprüft. Vier Browsermodi EN/de_DE_formal, JavaScript an/aus, prüfen Filter, normale Einzelkartenbreite, mobilen Überlauf und Verlaufsbedienung. Für 65 benannte/anonyme Funktionen sind geordnete Parameter-/Rückgabeverträge geprüft.

Ausführung: WordPress 6.7 Netzwerk, PHP 8.4.5, entbehrliche Testdaten. PHP 8.0 und lizenzierte Builder nicht erneut geprüft. Historische Ergebnisse bleiben historisch. Keine maßgebliche Host-Entwicklungsquelle, veröffentlichtes ZIP oder Updater-Engine überschrieben. Freigegebenen Online-Katalog gemeinsam mit dem Komponentenwechsel veröffentlichen; Daily 1.0.1 erhält erst nach tatsächlichem Release ein öffentliches Katalogpaket.

Belege: 29 Katalog-/Paket-/Versionsprüfungen, 33 Feed-/Brückenprüfungen, vier Manifest-/Erstaktivierungsprüfungen, zwei Online-Übergabeprüfungen mit altem Cache, 19 Netzwerk-Lesungsprüfungen, 16 Datenbereinigungsprüfungen und 25 Netzwerk-/Neusiteprüfungen (133 gezielte Assertions). Zusätzliche Komponentenwahl-/Plattformprüfungen bestehen auf WordPress 6.4 und 7.1.2. WordPress 6.4 meldet unter PHP 8.4 eine Core-Deprecation für einen nullable-Parameter; keine neue Library-Warnung festgestellt.

Drei zusätzliche Prüfungen einer fehlschlagenden Runtime-Factory bestätigen Erhalt der bisherigen Laufzeit, Entfernung teilweise registrierter Callbacks und Erhalt eines unabhängigen Aktivierungshooks.

Zwei Erst-Host-Prüfungen bestätigen native Netzwerkaktivierung und gewählte 0.6.1 ohne vorherige Library-Laufzeit.

Der Einstellungs-Footer zeigt das lokale SVG-Icon, die Version und den Verlaufslink mit Abstand. Seitentitel: deckerweb Plugin Library; Katalogöffnung als sekundäre Schaltfläche. Desktop-/Mobilansicht und Verlauf/Escape nach diesen Anpassungen geprüft.
