# Validation 1.2.0

[Deutsch](VALIDATION-1.2.0-de.md)

Published 30 October 2026. Status filters, result counts, compact controls and inline action recovery were tested in an isolated WordPress 7.1.2 / PHP 8.4.5 installation. WordPress 6.4 received a targeted rendering check. All 30 approved original plugin packages were checked for identity, archive safety and SHA256.

A user confirmed a successful FTPS (FTP over SSL) test on 30 October 2026. SSH has not been tested; no SSH compatibility claim is made. PHP 8.0 execution and a full new Multisite action matrix remain untested.

Official Plugin Check 2.1.0 leaves 34 individually assessed contextual Library findings, unchanged in type from 1.1.0. These do not constitute a blanket security guarantee. The component is tested embedded in a reference host, not as a standalone plugin.


Published catalog revision: 2026-10-30.1. Package versions and image provenance are recorded in [Catalog sources](CATALOG-SOURCES-1.2.0.json).
