# Optionale Anbindung öffentlicher Updater

[English](UPDATER.md)

Installation, Aktivierung und ausdrücklich gewählte Updates erfolgen in der Katalogkarte. Updates verwenden die native Plugin_Upgrader-Stapelverarbeitung für ein ausgewähltes Plugin und erhalten den Aktivierungsbereich. Bereits vorhandene Plugins ohne Updater können nach exaktem Namen und Repository-Headerprüfung übernommen werden. Fremde Update-URI oder abweichende vorhandene Updateangebote werden abgewiesen; keine konkurrierende Übernahme. Freigegebene Pakete werden vor Austausch auf Hash und Identität geprüft. Einstellungen/Inhalte werden nicht deinstalliert. Gemeinsame Einstellungen speichern inline; Katalogaktualisierung erhält die aktuelle Admin-URL. Unterbrochene Aktionen prüfen den physischen Zustand, ohne erfolgreiche Schreibvorgänge zu wiederholen. Dateisystemzugangsdaten bleiben im WordPress-Dialog. Ohne JavaScript bleiben Aktionen im Admin; Updates mit Dateisystemzugangsdaten nutzen die native Pluginverwaltung. Externe Produkt-/Doku-/Supportlinks sind freiwillig und öffnen separat.
