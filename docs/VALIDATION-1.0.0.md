# Validation 1.0.0

Checked in isolated WordPress 7.1.2 installations with PHP 8.4.5 and SQLite. The 23 original release packages pass checksum and archive validation. Actual catalog readers 0.6.0, 0.7.0, 0.8.1 and 0.9.0 accept the candidate metadata. Tests cover five sorting modes, stable random order, per-user preferences, Single Site permission for Multisite Toolbar Additions, offline catalog provenance without HTTP requests, bounded diagnostics, host-domain German and formal German, and administrator/subscriber nonce and capability checks. Native MTA 3.1.0 to 4.1.0 updates preserve single-site/network activation and stored data. Browser checks cover personal sorting, inline filtering, persistence, one-card width, diagnostics and modal visibility/closing under conflicting styles and an overwritten instance close method. Library installation succeeds with Git Updater 14.4.2 and 14.4.2.3 in the tested mixed-version configuration; the old 0.9.0 control reproduces the 14.4.2 abort. This does not establish compatibility with every Git Updater release or every third-party update provider.

PHP 8.0 execution, a new WordPress 6.4 run, real FTP/SSH connections, persistent external object cache and complete commercial-builder feature tests were not performed in this cycle. Test downloads use locally supplied verified original release packages. No production installation or public release was performed.
