# Release-Prüfung · 0.6.0

[English](VALIDATION.md)

Geprüft am 6. Oktober 2026: Der überarbeitete Katalog von 0.6.0 enthält 17 eindeutige freigegebene Plugins, 15 aktuelle lokale Originalicons und zwei dezente Text-Fallbacks. QuickNav 5, Builder 7, Purify 3, Inhalte verwalten 4; Mehrfachzuordnungen erzeugen keine doppelten Karten.

182 Katalog-/Serien-/Quellen-/Abhängigkeits-/Paketprüfungen bestehen auf WordPress 6.4 und 7.1.2 sowie in einem WordPress-6.7-Netzwerk. Dazu gehören Kompatibilität älterer Leser, Ablehnung doppelter/unbekannter/widersprüchlicher Serien, Entfernung der Websitehosts als Katalogquellen und fehlende/inaktive/aktive Lite-Abhängigkeiten. 33 Cache-/Providerprüfungen bestehen; native Einzel- und Sammelupdates im Hintergrund erhalten frische Freigabe und Prüfsummenprüfung. Browserprüfungen umfassen beide Sprachen, JavaScript an/aus, alle 17 Karten und 15 lokalen Icons, 19 Badges, Mehrfachserienfilter, Enter/Suche/Zurücksetzen und mobile Darstellung.

Ausgeführt mit PHP 8.4.5; Mindeststände bleiben WordPress 6.4 / PHP 8.0. Tatsächliches Verhalten der Zielplugins, FTP/SSH, PHP-8.0-Ausführung und Meldekonfiguration der Host-Repositories bleiben Host-Prüfungen. Frühere 310 Assertions beziehen sich auf die ursprüngliche 0.6.0-Lieferung und sind keine zusätzlichen Prüfungen dieser Überarbeitung. Keine Host- oder kanonische Updaterquelle überschrieben. Das zentrale öffentliche JSON wird im Library-Repository veröffentlicht; Online-Abfragen bleiben optional und initial aus.
