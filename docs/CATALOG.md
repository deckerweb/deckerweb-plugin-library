# Online catalog and independent updates

[Deutsch](CATALOG-de.md)

The online catalog contains 23 approved public plugin releases. Each entry pins repository identity, plugin main file, version, original ZIP URL, SHA 256 and platform requirements. Updates are explicitly reviewed; no automatic enrollment. Online retrieval is optional and initially off, cached for 24 hours; installed-plugin update checks use an independent 12 hour cache. Package actions require fresh approval. Existing Library 0.6.0,0.7.0 and 0.8.1 readers accept the additive catalog fields, show supported series and retain conservative dependency checks. New local icons use versioned filenames where older bundled assets would otherwise be stale; older hosts use initials when the file is absent. No remote icons or executable code are loaded.

Site Essentials 0.9.0 is available under Tools and Admin, for single-site and Multisite. It requires WordPress 7.1.2 and PHP 8.2. Existing bundled Library copies use the SE initials until its original icon is included in a component build. The built-in offline catalog depends on the bundled Library version; refresh the optional online catalog to obtain current entries.
