# Assets and provenance

[Deutsch](ASSETS-de.md)

Local catalog icons are original deckerweb artwork from the approved plugin repositories or verified release ZIPs. Per-plugin provenance and SHA 256 are recorded in [Catalog sources](CATALOG-SOURCES-0.9.0.json). Icons are delivered locally; rendering does not contact GitHub. The existing approved blue/purple 1 B identity, bilingual 1280×640 banners, catalog overview and real example screenshots are retained. No new banner artwork or font files were generated or bundled for this release. The local settings-footer SVG is vector artwork. Existing artwork sources may reference system fonts; their existing license records remain with the assets. No stock artwork or commercial builder code is included.
