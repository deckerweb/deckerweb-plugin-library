# Assets and provenance

[Deutsch](ASSETS-de.md)

Local catalog icons are original deckerweb artwork from the approved plugin repositories or verified release ZIPs. Per-plugin provenance and SHA 256 are recorded in [Catalog sources](CATALOG-SOURCES-1.2.0.json). Icons are delivered locally; rendering does not contact GitHub. The existing approved blue/purple 1 B identity, bilingual 1280×640 banners, catalog overview and real example screenshots are retained. No new banner artwork or font files were generated or bundled for this release. The local settings-footer SVG is vector artwork. Existing artwork sources may reference system fonts; their existing license records remain with the assets. No stock artwork or commercial builder code is included.

Library 1.2.0 bundles 31 local catalog PNG files for 30 plugins, including the required German icon variant. One current original icon per plugin is the default; genuine language variants are retained. Current neutral English/German screenshots show compact filters and catalog revision 2026-10-30.1. Runtime ZIPs exclude presentation screenshots and marketing assets; these remain in repository documentation. See [Overview](../README.md).


Online catalog 2026-11-04.1 now contains 31 plugins. This does not add icon files to the unchanged 1.2.0 runtime package: WPCodeBox QuickNav currently uses WBQ. The 30-plugin screenshots and 31 PNG files described above document the original Library 1.2.0 delivery.
